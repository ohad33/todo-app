# רשימת משימות

**לאתר החי:** https://ohad33.github.io/todo-app/

## מה האפליקציה עושה
אפליקציה בדפדפן לניהול רשימת משימות פשוטה: מוסיפים משימות, עורכים אותן, מסמנים כבוצע ומוחקים.
האפליקציה בעברית ומוצגת מימין לשמאל.

## יכולות
- **הוספת משימה** — משימה חדשה מופיעה בראש הרשימה. כל משימה מכילה טקסט בלבד.
- **עריכה** — כפתור "ערוך" ליד כל משימה, ואז "שמור" או "בטל".
- **סימון כבוצע** — תיבת סימון ליד כל משימה. אפשר גם לבטל את הסימון. משימה שבוצעה נשארת במקומה, והטקסט שלה מוצג עם קו חוצה.
- **מחיקה** — כפתור "מחק", עם בקשת אישור לפני המחיקה.
- **הגנה מקלט ריק** — ניסיון להוסיף משימה ריקה, או לשמור עריכה עם טקסט ריק, מציג הודעת שגיאה.

## שמירת המידע
המשימות נשמרות ב-localStorage של הדפדפן. הן נשארות גם אחרי סגירת הדפדפן, אבל רק בדפדפן ובמחשב הזה, ולא עוברות למכשירים אחרים.
